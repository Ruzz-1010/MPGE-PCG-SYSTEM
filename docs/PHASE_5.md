## V2 requirements

Catch-up uses most urgent bucket (8–30 days → 30, 2–7 → 7, 1 → 1, 0 → due today, negative → expired); missed older buckets aren't replayed. Regional Admin and assigned Station Admin/Records Officers receive own dashboard notices. Inspectors and technical admins excluded by proposed policy. Alerts show vessel, recorded owner/operator, station, document/version, expiry and state. Required expired documents are review warnings only. No automatic Hold. Dashboard counts refresh with dashboard. Dedup uses existing partial unique indexes; transaction advisory lock serializes notification generation and actions. Queued/failed outdated notifications are cancelled at next check; delivered and acknowledged history retained. No actual SMS. Reserved fictional recipients only; explicit demo acknowledgement creates a simulated verified recipient, with disable action. No real verification or consent implied. Station Admin/Records Officers simulate successful/failed delivery manually; at most three attempts, compare expected state and attempt count, append history. Regional Admin can run scheduler on demand and read regional simulated outbox, cannot send. No network SMS provider or credentials. Candidate roles and thresholds require stakeholder approval.
